# sirio-demo

This repository holds one frozen pull request for the promo captures of [Sirio](https://github.com/ai-sirio/sirio), the desktop app for running coding agents side by side.

Pull request #1 ("Refresh the session cookie before it expires") stays open on purpose. It has one passing check, one failing check, an unresolved review thread and a comment, so Sirio's captures always show the same state.

Do not merge it, close it or push to its branch. Do not delete this repository.

The code is a tiny session helper with no dependencies. `npm run lint` type-checks it and `npm test` runs its tests.
